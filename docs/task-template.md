# C6 开发任务模板

新任务开始前复制本模板。任务描述以可验证结果为中心；实现过程中的临时发现不要自动扩大任务范围，应先记录并确认。

## 1. 目标

用一两句话说明要解决的用户问题，以及完成后用户能获得什么结果。

> 示例：用户完成一道错题后，可以在不刷新页面的情况下看到掌握度更新，并在离线重连后保持一致。
