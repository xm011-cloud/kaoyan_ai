# 学习计划用户流程 V1

## 主流程

```text
描述目标 → 提取目标/档案草稿 → 确认或标记未知
→ 追问影响路线骨架的问题 → 生成长期路线草稿
→ 确认路线 → 生成本周草稿 → 确认后创建任务
→ 今日执行 → 周中安全调整 → 周末复盘 → 下一周
```

## 关键交互

- 首轮只追问考试时间、科目形式、每周容量和固定占用；每题允许回答、标记“暂时不确定”或跳过，科目水平渐进补充。
- 用户自然语言描述先经过“系统理解 → 待确认问题”预览；只有点击确认才写入长期学习档案。
- 路线草稿展示不确定项、阶段目标、退出标准、各科策略、关键假设和风险；确认前用户可逐阶段编辑目标与退出标准。
- 周计划草稿展示本周目标、安排依据、关联阶段/里程碑、容量、成功标准和拟创建任务。
- 只有确认周计划后，才在一次事务中激活计划并创建任务。
- 调整先分类为临时容量变化、难度误判或长期目标变化，再展示保留、移动、取消和新增差异。
- 周末复盘采集实际时长、完成情况、延期原因、负荷和薄弱点；用户明确选择“只调整下一周”或“需要调整阶段”后，系统分别生成周计划或路线草稿，下一周继承这些信息，不从零开始。

## 页面结构

- 首页：目标、当前阶段、本周、今日四类摘要卡和直接行动。
- 计划中心 / 路线：长期路线与阶段。
- 计划中心 / 本周：草稿、执行与调整。
- 计划中心 / 今天：今日任务与开始入口。
- 计划中心 / 复盘：周复盘与历史变化。

移动端使用纵向列表，不要求自由网格。

## 异常与降级

- 无 AI Key：本地模板仍生成完整草稿，不直接写任务。
- AI 格式错误：保留现有计划并提示重试。
- 重复确认：返回首次结果，不重复创建任务。
- 草稿确认不进入离线重放队列，避免重复批量写入。
- 目标信息冲突：要求确认，不静默覆盖。
- 无路线：回退到阶段建议和探索流程。
- 含学习档案的探索路线默认走本地模板；长期保存本身不构成向外部 AI 发送档案的授权。
