# 学习证据账本

> 目标：让课程、任务、练习和错题复习准确推进长期路线，同时不把“做过”误判成“掌握”。

## 唯一事实源

`StudyEvidence` 记录已经发生的学习行为。`Task`、`StudySession`、`PracticeSession` 和 `WrongQuestion` 仍保存各自业务状态，里程碑复盘只从证据账本读取完成行为，不再按“同科目 + 时间范围”猜测练习或错题归属。

证据类型：

- `task_completion`：用户明确完成计划任务。
- `course_session`：课程学习会话完成，并保留时长与自评。
- `practice_session`：练习提交完成，并保留得分。
- `wrong_review`：一次错题复习评分。

## 归属与去重

- 证据可以同时关联 `taskId` 与 `milestoneId`；未知归属保持 `null`，不自动猜测。
- 任务已经关联里程碑时，课程、练习和错题沿任务链路继承归属。
- 独立学习行为可以由用户显式选择里程碑，但服务端必须校验用户所有权和科目。
- `(userId, kind, sourceId)` 唯一。接口重试只更新同一条证据，不重复累计。
- 取消任务完成会把证据标记为 `retracted`，不删除历史。

## 掌握边界

证据只回答“做过什么”，不能自行宣告“已经掌握”。系统达到阈值后只能提示复盘，里程碑状态仍由用户选择“已达成 / 继续巩固 / 需要重学”后更新。

## 历史数据

迁移只回填能够确定发生过的任务、课程、练习和错题复习。任务与课程可沿已有外键继承里程碑；旧练习和错题无法确定归属时进入未归属证据，不按标题、科目或日期猜测。
