# 学习计划 V1 验收标准

## 十秒方向感

用户进入首页十秒内能回答：长期方向、未确定目标、当前阶段、阶段退出标准、本周安排依据、今日开始入口。

## 核心行为

- 模糊目标可保存为 exploring，不虚构院校或日期。
- 区分用户陈述、自评、自检、行为证据和 AI 推断。
- 路线和周计划先产生 draft；确认周计划前不创建 Task。
- 规划访谈的问题可逐题回答、标记暂不确定或跳过；确认前不写入长期档案。
- 路线草稿的阶段目标和退出标准可编辑；active 路线不能被原地改写。
- 重新生成不覆盖 active 版本；重复确认不产生重复任务。
- 调整保留已完成、进行中和手动任务。
- 周报复盘先记录原因与调整范围；“调整下周”只生成周计划草稿，“调整阶段”只生成路线草稿，均不得自动生效。
- 首页核心卡均有入口，今日任务可直接开始或定位工具。
- 无 AI Key 仍可完成草稿、确认、执行和复盘。

## 代表样本

| 场景 | 必须体现 |
|---|---|
| 只知道想考计算机研究生 | 探索阶段、待确认项、公共基础 |
| 408 网络未学、数学弱、英语四级已过 | 区分事实与自评，网络新课与全科基础并行 |
| 不知道数学一或数学二 | 保留条件分支，不生成特定范围刚性任务 |
| 每周只有 10 小时 | 总时长不超容量并明确取舍 |
| 拒绝水平自检 | 保守计划、低可信标记、不阻塞 |
| 周中临时忙碌 | 只调整剩余任务 |
| 周报发现时间不足 | 保存复盘后生成下周草稿，已完成与手动任务不变 |
| 发现数学先修缺口 | 路线变更提案与影响确认 |
| 中途改院校或自命题 | 旧路线保留，新建候选版本 |
| AI 失败或无 Key | 保留现有计划并提供本地草稿 |
| 重复点击确认 | 一个 active 周计划和一批任务 |
| 历史任务无归属 | 保持可见，不错误回填 |

## 测试矩阵

- 状态迁移、单 active 约束、确认幂等和跨账号隔离。
- AI 输出的日期、容量、科目和动作类型由服务端校验。
- 导出与注销覆盖新增数据。
- 周报复盘的归属校验、保存和页面回显；复盘跳转只创建 draft，不直接变更 Task 或 active 路线。
- 探索目标不显示虚构值；路线展示退出标准；周计划展示依据和容量。
- 卡片标题、条目与按钮点击范围互不冲突；移动端可开始任务。
- 旧 Goal、StudyPath、Milestone、Task 和周起始兼容读取不回归。
- TypeScript、ESLint、生产构建通过；发布候选运行完整单 worker E2E。
