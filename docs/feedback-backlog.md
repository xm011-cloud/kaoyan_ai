# C6 反馈台

> 这不是让用户填写的测试表，而是把“用起来不对劲”的瞬间变成下一项明确改动的地方。

## 现在只看这三件事

| 优先级 | 你只要试一次 | 我们想确认什么 | 你只需告诉我 |
|---|---|---|---|
| 1 | 首页同时有今日任务和到期错题时，点主按钮开始学习 | 你是否知道应该先复习，还是被任务和错题两个入口弄乱 | “我以为应该先做 ___，但页面让我做 ___。” |
| 2 | 从今天任务添加一节 B 站/网课，再结束一次学习 | 课程链接、学习进度和下一步是否连在一起 | “我在 ___ 卡住了 / 不知道学完后该点什么。” |
| 3 | 复习一道到期错题，查看答案后留下易错点或方法 | 复习流程是否自然，评分和知识点是否让人困惑 | “这个按钮/选项我不理解，因为 ___。” |

不用一次做完三件事。任何一条反馈都足以开始处理。

## 给我反馈，只用这一句话

直接复制后随便写，不用判断严重级别：

```text
我在【页面或功能】想要【目的】，做到【哪一步】时出现【实际情况】；我原本以为会【期待结果】。
```

例如：

```text
我在【今日首页】想开始学习，看到一项任务和三道到期错题，不知道应该先点哪个；我原本以为系统会明确告诉我先复习还是先上课。
```

截图、录屏、链接都可直接附在这句话后面；没有也没关系。我负责补充复现步骤、优先级、测试和修复版本。

## 完成阶段 0 前仍需补的证据

- 新手：首页 → 首周探索 → 第一项任务 → 留下一句理解 → 回首页；
- 正常用户：首页 → 今日任务 → 课程/练习 → 结束学习 → 回首页；
- 积累用户：首页 → 今日复盘 → 连续复习 → 留下策略 → 知识点回看 → 原题。

自动化测试只能证明不回归；以上三条真实操作路径才决定是否进入下一阶段。
